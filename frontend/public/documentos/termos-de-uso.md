# Termos de Uso - RadioDent

Versao: 1.0 - 22/09/2026

O RadioDent é uma plataforma acadêmica de treino radiográfico. Não substitui avaliação clínica, diagnóstico, laudo profissional ou atendimento odontológico.

O usuário deve proteger a conta, usar dados corretos e incluir apenas conteúdo para o qual possua autorização. É proibido acessar dados de terceiros, elevar privilégios, compartilhar credenciais ou inserir dados identificáveis de pacientes sem base e controles adequados.

O uso indevido pode bloquear a conta. O serviço pode ter manutenção ou encerramento no contexto acadêmico.

A Política de Privacidade é separada e não elimina direitos legais do titular.
